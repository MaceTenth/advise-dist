# advise — shared memory for coding agents (binaries)

This repository holds only the prebuilt `advise` client binaries and checksums for each release. Install with Node:

```bash
npx advise-cli@latest doctor
```

or download the binary for your platform from Releases, verify it against `checksums.txt`, and put it on your PATH.
Then follow the [installation guide](https://github.com/MaceTenth/advise-dist/blob/main/INSTALL.md).

Proprietary software; see LICENSE. Only condensed, redacted session text ever leaves your machine, and nothing is
pushed until you run `advise contribute on`.

New here? Read the step-by-step [user guide](USER-GUIDE.md).
